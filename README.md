# readonly-mcp

## 概要（30秒で読めます）

指定したフォルダの文書だけを、AIが「一覧を見る」「語句で探す」「必要な行だけ読む」ことができるMCPサーバー（AIと外部の道具をつなぐ共通の仕組みの、道具側）です。

- 読み取り専用です。書き込み・削除・外部への通信の機能はありません。
- 読んだ記録（いつ・どの道具で・どのファイルの何行目か）を `logs/access_log.jsonl` に残します。
- Pythonの標準機能だけで動きます。追加のインストールが不要なので、インターネットにつながらない端末（閉域）にも、ファイルを運ぶだけで持ち込めます。

## できること

| 道具 | 内容 |
|---|---|
| `list_documents` | 文書フォルダ内の .txt .md .csv の一覧と行数 |
| `search_documents` | 語句を含む行を、ファイル名・行番号付きで返す（50件まで） |
| `read_document` | 指定した行だけを行番号付きで返す（1回400行まで） |

文書フォルダの外のファイル、2MBを超えるファイル、上の3種類以外のファイルは読めません。

## 動作確認

```
python test_client.py
```

9項目（初期化、道具の一覧、一覧・検索・指定行の読み取り、フォルダ外の拒否、書き込みの道具がないこと、ping、記録が残ること）を確かめます。

公式のMCP Python SDK（2.3.0）のクライアントから接続し、初期化・道具の一覧・読み取りができることも確認しています（Linux上、2026年10月）。

## Claude Desktop（Windows）で使う

1. このフォルダを `C:\Users\<ユーザー名>\work\readonly-mcp` に置きます。
2. 読ませたい文書を `docs` フォルダに入れます。公開して問題のない文書だけにしてください。
3. `%APPDATA%\Claude\claude_desktop_config.json` に、`claude_desktop_config.example.json` の内容を書き足し、パスを自分の置き場所に合わせます。
4. Claude Desktop を再起動します。

## 記録の例

```
{"time_utc": "2026-10-20T23:47:02+00:00", "tool": "read_document", "path": "sample.md", "start_line": 6, "end_line": 7}
```

時刻は協定世界時（UTC）です。日本時間は9時間足してください。

## 限界

- PDFやWordは読めません。テキストに変換してから入れてください。
- 意味の近さで探す機能（ベクトル検索）はありません。語句の一致だけで探します。
- 通信方式は標準入出力（同じ端末の中でのやり取り）だけです。
